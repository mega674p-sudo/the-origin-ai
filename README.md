# GIGA PHONE AI

An autonomous AI agent designed for Termux / Ubuntu environments, controlled via Telegram, featuring robust self-correction and automated execution pipelines.

## Features
- **Secure Shell Execution**: Safely run bash commands with exit code interception.
- **Self-Correction Engine**: Automatically diagnoses and repairs common CLI errors (missing packages, permission issues).
- **Telegram Integration**: Real-time status updates and error logging.
- **Service Orchestration**: n8n deployment and automated media pipelines.
